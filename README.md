# Nehru ERP

Complete ERP platform for colleges and educational institutions.

## Modules
- Student Management
- Attendance Management
- Internal Marks
- University Results
- Fee Management
- Timetable Generator
- Staff Portal
- Chairman Dashboard

## Technology Stack
- Angular
- Node.js
- Express.js
- PostgreSQL
